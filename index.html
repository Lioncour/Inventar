About

Inventar

A personal inventory. Photos go into a Google Drive folder, a job cuts out the background, and the things end up here with tags.

How it works

  1. Take a photo with the Fototagger app, or drop an image into the Drive folder.
  2. Every hour a GitHub Action downloads new photos and removes the background with BiRefNet.
  3. A rough colour tag is read from the cut-out. Tags sent from the app are kept as manual tags.
  4. The item appears here. More tags can be added in the admin page.

Tags

Tags are key:value. Filters exist for color, size, room and price. Anything else is searchable.

Admin

Open /admin.html to edit tags. Download items.json and commit it to publish them.
