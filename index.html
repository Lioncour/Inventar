About Inventar

Inventar is a personal item inventory system that automatically processes and organizes your belongings using AI and automation.

Features

  • Automated Processing: Images are automatically downloaded from Google Drive and processed
  • Background Removal: Clean, professional-looking item photos with white backgrounds
  • AI Tagging: Automatic color and size detection
  • Custom Tags: Add your own tags for size, color, price, and room location
  • Smart Sorting: Sort items by various criteria with smooth animations
  • Multi-Filter System: Filter by multiple criteria simultaneously
  • Responsive Design: Works perfectly on all devices

How It Works

  1. Upload images to your designated Google Drive folder
  2. GitHub Actions automatically processes new images every hour
  3. Backgrounds are removed and AI tags are generated
  4. Items appear in your inventory with automatic updates
  5. Use the admin panel to add custom tags and organize your items

Admin Panel

Access the admin panel at /admin.html to add custom tags and manage your inventory.
